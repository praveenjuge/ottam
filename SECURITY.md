# Security policy

Please report suspected vulnerabilities privately to [hello@praveenjuge.com](mailto:hello@praveenjuge.com). Do not open a public issue with exploit details, credentials, listener data, unpublished stories, or private media URLs.

Include the affected surface, reproduction steps, impact, and any suggested mitigation. You can expect an acknowledgement within five business days. There is currently no paid bug-bounty program.

Supported security fixes target the current `main` branch. Production credentials are held by Clerk, Convex, Cloudflare, ElevenLabs, and Vercel; the iOS binary contains only public Clerk and Convex configuration.
